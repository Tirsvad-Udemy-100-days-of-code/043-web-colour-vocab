# Bermula

## Keperluan

Pelayar web. Tiada langkah binaan, tiada pakej untuk dipasang dan tiada pelayan.

## Dapatkan fail

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/043-web-colour-vocab.git
cd 043-web-colour-vocab
```

## Buka halaman

Buka `src/index.html` dalam pelayar, dengan klik dua kali padanya atau dari terminal:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

## Semaknya

Semakan ialah senarai semak manual, kerana seluruh produk ialah satu halaman statik. Buka `src/index.html`, kemudian lalui item dalam `tests/manual-checklist.md` (tajuk, lima kad warna, warna helaian gaya, saiz gambar, tetingkap sempit dan tajuk halaman).
