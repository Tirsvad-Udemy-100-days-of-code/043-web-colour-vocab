# Kom godt i gang

## Krav

En webbrowser. Der er intet build-trin, ingen pakke at installere og ingen server.

## Hent filerne

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/043-web-colour-vocab.git
cd 043-web-colour-vocab
```

## Åbn siden

Åbn `src/index.html` i en browser, ved at dobbeltklikke på den eller fra en terminal:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

## Kontrollér den

Kontrollen er en manuel tjekliste, fordi hele produktet er én statisk side. Åbn `src/index.html`, og gennemgå punkterne i `tests/manual-checklist.md` (overskriften, de fem farvekort, stilarkets farver, billedstørrelsen, et smalt vindue og sidens titel).
