# Getting Started

## Requirements

A web browser. There is no build step, no package to install and no server.

## Get the files

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/043-web-colour-vocab.git
cd 043-web-colour-vocab
```

## Open the page

Open `src/index.html` in a browser, by double-clicking it or from a terminal:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

## Check it

The check is a manual checklist, because the whole product is one static page. Open `src/index.html`, then go through the items of `tests/manual-checklist.md` (the heading, the five colour cards, the stylesheet colours, the picture size, a narrow window and the page title).
